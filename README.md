# 🤖 Balle Bot

> Landing page responsiva para um bot de gerenciamento de comunidades.

O **Balle Bot** é um projeto desenvolvido para apresentar uma proposta de bot voltado à segurança e administração de comunidades. A página apresenta suas principais funcionalidades de forma simples e visual, utilizando uma identidade inspirada no projeto original desenvolvido durante os estudos de desenvolvimento web.

O projeto também foi utilizado como prática de **HTML5, CSS3, responsividade, organização de código e publicação de páginas com GitHub Pages**.

---

## ✨ Funcionalidades apresentadas

A página apresenta três propostas principais para o bot:

* 🛡️ **Sistema de verificação**

  * Verificação de novos membros para identificar possíveis bots.

* 🚫 **Banimento automático**

  * Identificação e banimento de links suspeitos enviados na comunidade.

* ⚠️ **Sistema de avisos e banimento manual**

  * Recursos destinados à administração e moderação da comunidade.

> **Observação:** nesta versão, essas funcionalidades são apresentadas como parte da interface/proposta do projeto. A implementação de um bot real ainda não faz parte deste repositório.

## 📱 Responsividade

O projeto foi desenvolvido para se adaptar a diferentes tamanhos de tela.

### 🖥️ Desktop

Layout horizontal com:

* Logo;
* Menu de navegação;
* Conteúdo principal;
* Ilustração do bot.

### 📱 Tablet

O espaçamento, tamanho das fontes e imagens são ajustados para telas intermediárias.

### 📱 Mobile

O conteúdo principal passa para uma organização vertical, com:

* Menu adaptável;
* Títulos redimensionados;
* Imagem responsiva;
* Botão centralizado;
* Conteúdo ajustado para telas menores.
